# Security Policy

Security fixes are provided for the latest tagged release.

Please use GitHub's private vulnerability reporting. Do not open a public issue containing
credentials, private transcripts, identifying paths, or exploit details. Include the affected
version, a minimal reproduction, impact, and any suggested mitigation.

Treat evaluation inputs and raw outputs as sensitive by default. Redact before provider calls,
keep raw transcripts outside version control, and never place API keys in command arguments or
study configs.
